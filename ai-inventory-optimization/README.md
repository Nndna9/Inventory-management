# AI-Powered Inventory Management & Supply Chain Optimization System

Streamlit application for the "AI Applications in Reorder Point & Inventory Management" exercise.
All data is synthetic.

## Install (Windows)

```
cd Documents\ai-inventory-optimization
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```
python scripts/run_pipeline.py     # rebuilds data, reports and models (about 2 minutes; already built once)
streamlit run app.py
```

## Test

```
python -m pytest -q
```

## Layout

- `app.py` - entry point and navigation
- `dashboard/` - one module per page; pages only display, they do not calculate
- `src/` - all calculations (`data_processing`, `feature_engineering`, `services`, ...)
- `config/settings.yaml` - paths, split dates, service levels, ASSUMED cost parameters
- `data/raw/` - original dataset (never modified); `data/processed/` - cleaned data and features
- `reports/` - data quality, EDA, data dictionary, model evaluation (all generated by the pipeline)
- `models/` - trained forecasting model and its evaluation metadata
- `data/raw/updates/` - new data added through the dashboard (kept apart from the original)
- `tests/` - pytest suite, including headless dashboard tests

## Data labels

- Original: `data/raw/` synthetic dataset as provided
- Derived: columns and features calculated from it (`data/processed/`)
- Assumed: cost parameters in `config/settings.yaml` (not in the dataset)
